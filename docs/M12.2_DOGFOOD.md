# M12.2 Smart Router dogfood

Date: 2026-08-14

This is local evidence for M12.2. It is not a public release, an acceptance
claim, or proof of live provider inference.

## Scope

- Pi `0.84.1`, Node.js `v22.23.0`, disposable injected configuration roots.
- No live Pi configuration, provider account, credential, tag, push, npm
  publication, or GitHub release was modified.
- Live Primary/Fallback triage was not called. The current checkout had no
  securely available 9Router credential or registered triage route, so no
  credential was copied, printed, or manufactured for this check.

## Isolated Pi TUI

Using `pi --offline --no-extensions -e dist/host/pi-extension.js` with
disposable `PI_MULTI_ORCH_CONFIG_ROOT` and `PI_CODING_AGENT_DIR` roots:

- `Explain what a TypeScript interface is` reached the editor with no Smart
  Routing banner and was exited without a provider call.
- `Fix the bug in src/auth.ts and add tests, then verify independently` showed
  `Orchestrator recommended`; selecting the default `Run as Mission` created
  exactly one draft Mission whose title and goal matched the original text.
- The generated MissionStore was queried directly after the run; no session
  or live agent state was used.
